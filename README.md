## 🚀 How to Run Locally

### Option 1: Direct Browser Launch
Simply double click or open `index.html` in any modern web browser.

### Option 2: Local HTTP Server
```bash
# Using Python
python -m http.server 3000

# Or using npx serve
npx serve .
```
Then visit `http://localhost:3000`.

## ☁️ Deploying to Vercel

### Method 1: Vercel CLI
```bash
npx vercel
```

### Method 2: GitHub / Vercel Web Dashboard
1. Push this directory to your GitHub repository.
2. Go to [vercel.com/new](https://vercel.com/new).
3. Import the repository and click **Deploy**. Vercel will immediately recognize the zero-config static site.
